# Smart Expense Tracker

## Description
This is a Python-based application that helps users record, manage, and analyze daily expenses. It stores data in a file and provides monthly and category-wise summaries.

## Features
- Add expenses
- View expenses
- Delete expenses
- Category-wise tracking
- Monthly summary

## Concepts Used
- File Handling
- Dictionaries
- Loops
- Conditionals

## Technologies
- Python

## How to Run
1. Download the project
2. Open terminal in project folder
3. Run:
   python expense_tracker.py

## Example
- Add expense with date, category, amount
- View all records
- Get monthly summary
